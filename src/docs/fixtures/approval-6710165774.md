### 🖊 결재 요청 (2026-11-08)
**종류**: 결정 요청
**요청**: 코더(루프)
**내용**: #1 코드는 PR #33으로 올렸습니다. 실제로 "내 세션 → 1~2초 안에 사무실 목록"을 확인하려면 계정 권한이 필요한 설정 세 가지가 남습니다. 누가 어디까지 할지 정해 주세요.
- ① Supabase(방명록과 같은 프로젝트) SQL Editor에서 `supabase/office.sql` 실행
- ② agent-office를 Vercel 새 프로젝트로 가져오기. 환경 변수: `SUPABASE_URL`, `SUPABASE_SECRET_KEY`(서버용), `OFFICE_HOOK_TOKEN`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`(읽기 전용 키). 그 뒤 dev → main 배포
- ③ 내 PC에 훅 등록: `~/.agent-office/hook.json`(주소·토큰), `~/.claude/settings.json` 사용자 설정의 `hooks`에 다섯 이벤트 추가(`hooks/README.md`). 네 세션의 이름에 역할 낱말(기획·Blender·디자이너·코더)이 있어야 함

**선택지**
1. ①②는 사용자가 하고, ③은 코더가 함 (추천). 토큰은 코더가 만들어 로컬 `hook.json`에만 저장하고, 터미널로 값을 알려 드리면 Vercel에 붙여 넣습니다. 코더가 `"log": true`로 확인한 뒤 결과를 여기 댓글로 남깁니다
2. ①②③ 모두 사용자가 `hooks/README.md`를 보고 직접 함
3. 지금은 보류하고 배포는 #24(문서 수집)·#25(결재)와 함께 함

**추천 이유**: ①②는 계정 권한이 있어야 하고 비밀 키를 다룹니다. ③은 경로와 설정 형식을 틀리기 쉬운데, 코더가 넣으면 `hook.log`로 바로 확인할 수 있습니다. 훅은 `async`라 세션을 느리게 하지 않고, 실패해도 조용히 끝납니다.
