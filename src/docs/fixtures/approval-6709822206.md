### 🖊 결재 요청 (2026-11-08)
**종류**: 결정 요청
**요청**: 디자인
**내용**: 에이전트 네 명(기획·3D·디자인·코더)의 이름 안 하나를 골라 주세요. 섞어서 고르셔도 됩니다(예: “1번인데 코더만 코디”).

**선택지**
1. A 사물 이름: 메모 MEMO · 메시 MESH · 휴 HUE · 루프 LOOP (추천)
2. B 사람 이름: 피아 PIA · 레니 RENI · 디디 DIDI · 코디 CODY
3. C 우리말: 짜임 · 빚음 · 그림 · 엮음 (이름표도 한글)

**추천 이유**: 이름만 들어도 역할이 짐작됩니다(메모 = 정리, 메시 = 3D 메시, 휴 = 색상, 루프 = 반복문). 한글·영문 모두 짧아서, 책상 방 로봇의 `RB-01 · THINKING` 같은 영문 대문자 이름표에 그대로 들어갑니다. 휴(HUE)는 “휴식”과 겹쳐서, 쉬는 장면에서 작은 웃음거리가 됩니다.
