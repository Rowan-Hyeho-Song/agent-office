**결정**
- 시안·토큰·근거 문서를 PR #23으로 올렸다. 근거는 `docs/design/office-ui.md`에 있다.
- 회의 재연 확인 결과: “한 사람에 말풍선 하나, 상대의 지난 말은 회색” 규칙이라 몇 번을 주고받아도 화면에는 둘까지만 남는다. 3번 주고받는 시안에서 어색한 곳은 없었다. 재연 문장은 **36자 안으로 자르기**를 권한다. 넘으면 말줄임이 되고, 원문은 화면 읽기 로그와 회의록에 남는다.
- 대화 중 상대의 지난 말풍선은 투명도 50% 대신 **회색 테두리 + 보조 글자색**으로 흐린다. 투명도는 밝은 배경에서 글자 대비를 깨뜨렸다.
- 하위 에이전트는 쓰지 않았다. 리서치 범위가 작고 시각 판단과 시안이 맞물려 있어 직접 했다.

**후속**
- 기획: “테스트 실행 중” 판정 규칙이 필요하다. 훅이 도구 이름만 보내므로 Bash 중 테스트를 가려낼 수 없다. 규칙을 만들지, 문구를 뺄지 정해야 한다(#1).
- 기획 / Blender: 퇴근 상태에서 모니터가 꺼져도 책상에 구워진 모니터 빛이 남는지 확인이 필요하다.
- 코더: 토큰 이름에 대한 회신을 기다린다. 바꿀 것이 있으면 디자이너가 토큰 파일을 고친다.
- #5에서 에이전트 이름·색이 정해지면 `--agent-N` 값과 탭 문구만 바꾼다.
