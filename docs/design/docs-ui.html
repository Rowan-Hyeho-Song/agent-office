#18 말풍선·출입문과 같은 가족: 서류철 탭, 아이보리 글자, 깎은 모서리. 결재는 호박 하나로 통일하고(메모의 결재 도장, 책상 방 단말기 색), 종류는 아이콘·글자·배지 모양으로, 누가 올렸는지는 에이전트 색 띠로 보인다. 클래스 이름은 #25 구현(.approval-*)에 맞췄다.

1. 결재함

목록 → 한 건 → 결재목록 카드 = 종류 배지 · 제목 · 요청 에이전트 · 파일철. 한 건 = 내용(제한된 마크다운, 표는 가로 스크롤) → 선택지(추천 꼬리표, 추천 이유는 접힘) → 의견 → 결재. 오래된 것부터.
종류는 모양으로결정 요청 = 갈림길 아이콘·테두리 배지, 문서 공개 = 문서 아이콘·채운 배지, 산출물 확인 = 도장 아이콘·사선 배지. 색은 같은 호박: 에이전트 색과 섞이지 않게.
반려는 이유가 있어야반려·“고쳐서 공개”·“계속 SECRET”을 고르면 의견 칸이 필수로 바뀌고(빨간 *, 고른 것마다 안내가 다름), 비어 있으면 결재 버튼이 꺼진다. 서버도 400으로 막는다(#25).
결재 = 쾅메모의 결재 도장이 0.4초 만에 찍히고 판이 2px 눌린다. “#이슈에 ✅ 댓글을 남겼어요” 뒤 1.2초에 다음 건. 움직임 줄이기면 도장이 찍힌 채 바로 나타난다.

2. 서재 문서 뷰어

폴더 → 파일철 → 문서왼쪽에 프로젝트 폴더와 파일철(이슈), 오른쪽에 파일철 하나를 순서대로 읽는 목차(기획서 → 회의록 → 결정 → 보고서). 서재의 책 한 권 = 파일철 하나.
긴 글은 종이 위에서문서 본문만 아이보리 종이(--paper)에 검은 글자(13.8:1). 어두운 사무실 화면 안에서 “서류를 펼쳤다”가 바로 읽히고, 긴 글을 읽기에도 편하다.
회의록 = 대화협의 기록 표 한 줄 = 말 한 번. 보낸 쪽 이름표와 색 띠, 받는 쪽은 “→ 휴”. 사용자(ROWAN)는 오른쪽 호박 말풍선. 결정·후속은 아래 붙은 메모지.
SECRET = 서류철 표지마닐라 표지에 SECRET 도장, 종류·폴더·날짜·참여 에이전트만. 본문은 검은 줄. private는 제목·폴더도 지운다. 결재되면 도장이 떨어지고 표지가 열린다.

3. 화이트보드 칸반

흰 보드에 마커와 카드모델의 보드는 흰색(#f4f4f0)이다. 그래서 캔버스는 투명 바탕 위에 카드·메모지·마커 글씨만 그린다. 구운 보드 음영이 그대로 비쳐 “보드에 붙인 카드”로 보인다.
멀리서는 칸별 덩어리기본 카메라에서 보드는 가로 약 160px. 글자는 안 읽히고 칸마다 쌓인 카드 수와 에이전트 색 띠, 노란 결정 메모지 셋이 보인다. 1/4 거리부터 48px 제목이 12px로 읽힌다(#18 모니터와 같은 규칙).
칸당 카드 4장까지진행 중 · 검토 · 완료, 칸마다 최근 4장 + “+N”. 카드 = 에이전트 색 띠 · #번호 · 제목 두 줄. 오른쪽 결정 메모지 3장(최근 결정).
