결재함 · 문서 뷰어 · 화이트보드

#18 말풍선·출입문과 같은 가족: 서류철 탭, 아이보리 글자, 깎은 모서리. 결재는 호박 하나로 통일하고(메모의 결재 도장, 책상 방 단말기 색), 종류는 아이콘·글자·배지 모양으로, 누가 올렸는지는 에이전트 색 띠로 보인다. 클래스 이름은 #25 구현(.approval-*)에 맞췄다.

1. 결재함

목록 → 한 건 → 결재목록 카드 = 종류 배지 · 제목 · 요청 에이전트 · 파일철. 한 건 = 내용(제한된 마크다운, 표는 가로 스크롤) → 선택지(추천 꼬리표, 추천 이유는 접힘) → 의견 → 결재. 오래된 것부터.
종류는 모양으로결정 요청 = 갈림길 아이콘·테두리 배지, 문서 공개 = 문서 아이콘·채운 배지, 산출물 확인 = 도장 아이콘·사선 배지. 색은 같은 호박: 에이전트 색과 섞이지 않게.
반려는 이유가 있어야반려·“계속 SECRET”을 고르면 의견 칸이 필수로 바뀌고(빨간 *), 비어 있으면 결재 버튼이 꺼진다. 서버도 400으로 막는다(#25).
결재 = 쾅메모의 결재 도장이 0.4초 만에 찍히고 판이 2px 눌린다. “#이슈에 ✅ 댓글을 남겼어요” 뒤 1.2초에 다음 건. 움직임 줄이기면 도장이 찍힌 채 바로 나타난다.
