- 나누기: 자리 쓰기 45% · 보드 55%. 걷기는 실제 걸린 시간을 쓰고, 남는 시간을 두 덩어리에 그 비율로 나눈다.
- 각 덩어리는 아래 "동작 조각"을 시간이 찰 때까지 이어 붙인다. 조각을 끝까지 하지 못할 만큼 남으면 그 덩어리를 끝낸다(조각 중간에 끊지 않음).
- 정리가 2분보다 일찍 끝나야 하면(일 신호가 다시 옴), 지금 조각을 마치고 바로 `working`으로 간다(#186 그대로).

## 2. 자리에서 쓰기 (조각)

손 값은 grips.md "태블릿 펜 · 마커"(삼각 잡기)와 agents.md 2.7이다. 왼손은 카드 위에 손바닥을 아래로 누른다(전부 0.1).

| 조각 | 시간 | 동작 |
|---|---|---|
| **줄 쓰기** | 1.6–2.4초 | 펜 끝이 카드 위에서 왼 → 오로 4–6 cm 움직이며(손목 ±1 cm 흔들림, 0.12초마다 작은 위아래) 줄 하나를 쓴다. 머리 2° 따라 움직임 |
| **줄 바꿈** | 0.3초 | 펜을 1 cm 들어 왼쪽 끝 · 한 줄 아래(8 mm)로 옮김 |
| **펜 끝 톡톡** | 0.8초 | 쓰다 멈추고 펜 끝으로 카드를 두 번 톡톡(0.15초씩), 머리 3° 갸웃. 표정 "생각" |
| **긋고 고쳐 쓰기** | 1.4초 | 방금 줄의 한 부분을 펜으로 가로로 빠르게 긋고(0.3초), 그 위에 다시 짧게 쓴다(1.1초) |
| **들어 읽기** | 1.8초 | 왼손으로 카드를 들어(서류 받침 손) 얼굴 앞 0.25 m에서 읽음. 머리 위아래 2° 두 번. 내려놓음 |
| **다음 카드** | 0.6초 | 다 쓴 카드를 왼쪽 더미로 밀고(0.3초, 지금 push), 새 카드를 앞으로 당김 |

- **한 장 = 줄 3–5개**(줄 쓰기 + 줄 바꿈)에 섞기 조각 1–2개(톡톡 · 긋기 · 들어 읽기 중)를 넣는다. 한 장 6–12초다.
- 카드 수는 지금 1–3장에서 **2–5장**으로 늘린다(덩어리 시간을 채울 만큼). 시각 씨앗으로 정한다.

## 3. 보드 앞 (조각)

보드 칸 앞에 서서 한다(지금 post 자리). 카드는 붙인 뒤에도 실제로 옮겨진다(보드 데이터는 바꾸지 않고 그 장면 동안만 위치가 바뀌었다 제자리, 아래 "바꾸기"만 예외).

| 조각 | 시간 | 동작 |
|---|---|---|
| **붙이기** | 1.2초 | 지금 그대로(OK 집기 → 대기 → 엄지 바닥 누름 → 놓음) |
| **물러나 생각** | 2.5–4초 | 0.5 m 뒤로 물러나(0.6초) 보드를 본다. 버릇 셋 중 하나: **턱 괴기**(오른손 주먹을 머리 아래 앞에, 왼손이 오른 팔꿈치 자리를 받침) · **팔짱**(두 손을 머리 아래 앞에서 엇갈림) · **갸웃**(머리 8°, 손은 쉼). 표정 "생각". 다시 다가감(0.6초) |
| **옮기기** | 1.4초 | 붙인 카드 하나를 OK 집기로 떼어(0.3초) 옆 칸(같은 열 위 · 아래)으로 옮겨 다시 누름 |
| **두 장 바꾸기** | 2.4초 | 카드 A를 떼어 왼손에 들고 → 카드 B를 A 자리로 → A를 B 자리로. 이것만 보드 데이터 순서가 실제로 바뀌어도 된다(코더 판단, 바꾸지 않으면 장면 끝에 제자리) |
| **바로잡기** | 0.7초 | 비뚤게 붙은 카드 모서리를 검지로 밀어 반듯하게(카드가 3–5° 돌아 0°로) |
| **짚기** | 0.5초 × 2–4 | 검지로 카드를 하나씩 짚으며 머리를 끄덕(위에서 아래로 훑기) |
| **마지막 보기** | 0.8초 | 한 걸음 물러나 전체를 보고 2° 끄덕 |

- 순서: **붙이기(모든 장) → 섞기 조각들 → 마지막 보기**. 섞기 조각은 물러나 생각 1–2번, 옮기기 · 바꾸기 · 바로잡기 중 2–3번, 짚기 1번을 시간이 찰 때까지 둔다.
- 붙일 때 일부러 1–2장을 3–5° 비뚤게 붙여 두면 "바로잡기"가 자연스럽다.

## 4. 섞는 규칙

- **같은 조각을 잇달아 두지 않는다**(줄 쓰기 · 줄 바꿈 · 붙이기 · 짚기는 예외).
- 버릇 조각(톡톡 · 긋기 · 들어 읽기 / 물러나 생각 · 옮기기 · 바꾸기 · 바로잡기)은 **최근 3개 안에 같은 것이 있으면 고르지 않는다.**
- 물러나 생각의 버릇 셋(턱 괴기 · 팔짱 · 갸웃)도 같은 정리 안에서 되풀이하지 않는다.
- 고르는 것은 시각 씨앗(`agent|since|k`)으로, 모든 방문자에게 같다(#135 결정성).
- **에이전트 성격**(가중치 ×2)

| 누구 | 쓰기 | 보드 |
|---|---|---|
| 메모 | 줄 쓰기 · 다음 카드(빠르고 많음) | 짚기 · 마지막 보기 |
| 메시 | 들어 읽기 | 물러나 생각(턱 괴기) · 바로잡기 |
| 휴 | 긋고 고쳐 쓰기 | 두 장 바꾸기 · 바로잡기 |
| 루프 | 펜 끝 톡톡 | 옮기기 |
| 에코 | 들어 읽기 | 물러나 생각(갸웃) |

## 5. 표시 · 표정 · 소리

- 이름표 단계는 그대로 둔다(카드 쓰는 중 · 카드 붙이러 가는 중 · 카드 붙이는 중 · 자리로 돌아가는 중 · 자리 정돈 중).
- 보드 앞 섞기 조각 동안은 `카드 정리 중`으로 바꾼다(붙이기가 다 끝난 뒤).
- 표정(#166): 쓰기 "집중", 톡톡 · 물러나 생각 "생각", 긋기 "의문" 0.6초, 마지막 보기 "뿌듯" 1초.
- 소리(#194): 펜 사각거림은 넣지 않는다(너무 잦음). 카드 누름만 작은 "톡"(종이)이다.

## 6. 기다릴 때 · 배속 · 움직임 줄이기

- 보드가 차 있으면 자리에서 쓰기 조각을 이어 간다(지금 "카드 다시 읽는 중" 대신 들어 읽기 · 톡톡 · 고쳐 쓰기를 섞음). 20초가 넘으면 지금처럼 책상에 둔다.
- ×4: 모두 4배다. ×16: 섞기 조각은 빼고 붙이기 · 정돈만(#158 단순화). 시간 채우기는 재생 시계 기준이다.
- 움직임 줄이기: 걷지 않는다. 자리 쓰기 → 카드가 보드에 페이드로 나타남 → 정돈 → 휴식. 조각 대신 표시만 바뀐다. 시간 채우기는 그대로 해서(가만히 쓰기 자세), 표시와 행동이 어긋나지 않게 한다.
