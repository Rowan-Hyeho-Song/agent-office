# 자리별 책상 꾸미기 (#32)

> 시안: [desks.html](desks.html) (브라우저로 열기) · 2026-11-08 · 그래픽 디자이너 세션 · **확정 (2026-11-08 결재, 승인)**. 모델링은 Blender #43, 데이터 연결은 코더 #44
> 네 에이전트가 #32에 남긴 🪴 책상 꾸미기 제안을 지금 책상 모델(`office_bake.py` `build_desk`)에 놓았다.

## 1. 원칙

- **손 자리는 비운다.**
  - 키보드(가로 ±0.21, 앞뒤 −0.005~0.125)와 그 앞, 오른쪽 마우스 자리(0.30)는 #28의 떠 있는 손이 타자 치고 오가는 곳이다.
  - 그래서 x ±0.28, z −0.03~0.31 띠와 마우스 둘레에는 소품을 두지 않는다.
  - #20 놀이 소품(라켓·컵·물뿌리개·말)은 책상에 놓이지 않으므로 겹치지 않는다.
- **양 끝과 모니터 옆에 모은다.**
  - 일할 때 방문자는 에이전트 머리 뒤에서 책상을 본다. 가운데(모니터 앞)는 머리(폭 0.42, 1.12 m)가 가린다.
  - 그래서 소품은 x 0.3 바깥 양 끝과 모니터 양옆에 놓았다.
- **멀리서는 빛과 색 덩어리.**
  - 기본 카메라(112 px/m)에서 10 cm 소품은 약 11px다.
  - 그래서 데이터와 이어지는 소품은 대부분 **빛**으로 상태를 말한다: 신호등, 링 조명, 램프, 태블릿. 나머지는 색 덩어리로 읽히면 충분하다.
- **원래 공통 소품은 주인 것으로.** 지금 책상에 있던 머그(전 자리), 화분(짝수 자리), 서류 더미(홀수 자리)는 주인이 고른 소품으로 바꿨다. 메시만 머그를 남겼다(빈 자리가 있고 싫다는 말이 없음).
- **LIVE = 앱이 바꾸는 노드.** 데이터와 이어지는 소품만 live(실시간 조명·발광·회전)이고, 나머지는 굽는다.

## 3. 요청 반영표

| 누구 | 요청 | 반영 |
|---|---|---|
| 메모 | 결재 도장, 키보드 오른쪽 끝 | 마우스(0.30)와 겹쳐 마우스 바깥(0.46, 앞쪽)으로 옮김. 손에 드는 소품이라 #20 소품 규칙(home·grip)을 따름 |
| 메모 | 화분·인형 같은 장식은 싫음 | 원래 화분과 머그를 뺌. 서류는 조금 쌓여 있음 |
| 메모 | IN = 결재 대기, OUT = 오늘 넘긴 일, 달력 = 오늘, 모래시계 = 결재 대기 중 | 반영. 서류 더미는 0~5장 단계, 달력 앞면은 캔버스 슬롯 |
| 메시 | 턴테이블·컬러 체커·링 조명·기본 도형 | 반영. 원래 서류 더미를 빼고 머그는 남김 |
| 메시 ↔ 휴 | 컬러 체커 카드 vs 색견본 부채(둘 다 색 참조) | 모양을 갈라 놓음: 메시는 납작한 카드를 모니터 받침에 기대 둠(탁한 24칸), 휴는 서 있는 부채(팀 4색). 멀리서는 휴 쪽만 선명한 색 |
| 휴 | 태블릿을 마우스 자리에 | 반영. 휴 책상만 마우스가 없음. 오른손 자리는 그대로라 타자·손 동작에 영향 없음 |
| 휴 | 램프와 색견본 부채가 둘 다 왼쪽 | 램프를 더 뒤(−0.52, −0.26)에 두고 머리를 숙여 부채를 위에서 비추게 함. 두 소품이 한 장면이 됨 |
| 루프 | 신호등 = 테스트·빌드 결과 | 반영. 노랑은 #1 activity로 바로, 초록·빨강은 종료 코드(후속, 코더) |
| 루프 | 고무 오리, 실패하면 고개를 돌림 | 오리는 굽고, 바라볼 점만 빈 노드로 |
| 루프 | “밤새는 개발자” 클리셰는 싫음 | 원래 머그와 서류를 빼고 케이블 클립으로 정돈. 보조 모니터 화면은 밝은 줄무늬 |
| 네 명 | 빛 소품이 셋(휴 램프, 메시 링 조명, 루프 신호등) | 모양과 색을 갈라 놓음: 숙인 따뜻한 흰빛 / 라벤더 고리 / 세 칸 탑. 메모는 빛 대신 서류 덩어리 |
