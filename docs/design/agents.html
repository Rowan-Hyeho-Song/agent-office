네 명의 에이전트

역할 = 자리 = 색 = 실루엣. 같은 로봇 몸(몸통·머리·양팔·호버 포드)에 머리 위와 몸통의 부품 두 개씩만 바꿔, 전경 거리(키 약 120px)와 일할 때 보이는 뒷모습에서 누가 누구인지 읽히게 했다. 손은 비워 둔다(타자·탁구채·컵을 들어야 하므로).

1. 네 명

스케치는 Blender 로봇의 실제 치수(m)를 그대로 썼다. 몸통 0.34 × 0.36, 머리 0.32 × 0.24, 호버 포드 r 0.15→0.10, 바닥에서 안테나 끝까지 1.18. 회색 점선 = 바뀌는 부품. 측면은 왼쪽이 앞(-z).

실루엣만 · 정면

더 멀리 · 키 60px

실루엣 시험: 색을 다 빼도 머리 위 모양(안테나+마이크 붐 / 축 기즈모 / 베레모 / 헤드폰 띠)이 넷 다 다르다. 기획의 헤드셋에 머리띠를 뺀 이유: 띠가 있으면 코더의 헤드폰과 윤곽이 비슷해졌다. 60px에서는 색과 머리 윤곽만 남는다. 그래서 색이 서로 구분되는 게 중요하다(4절).

4. 색
