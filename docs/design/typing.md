# 타자와 마우스 (#225)

> 2026-11-09 · 그래픽 디자이너 세션
> - 사용자 의견: 일할 때 열 손가락이 같은 박자로 와다다 떠는 대신, 실제 타이핑처럼 손가락마다 맡은 키를 누르고 키캡이 눌리게 하고, 마우스도 간간이 쓰게.
> - 손 값은 agents.md 2.7(굽힘 c, 마디 각 75° · 90° · 60° × c)과 같은 틀이다. 키보드는 #187 공통 키트(키캡 87개, 19.05 mm 간격)다.

## 1. 근거

- 운지 표는 입문 교재마다 기호 · 수정 키의 맡는 손가락이 조금씩 다르다. 가장 흔한 쪽을 썼다.
- 마우스 · 키보드 시간 비율을 잰 연구는 찾지 못했다. 4절 비율은 설문(키보드 선호)과 활동의 성격으로 정한 값이다.

## 2. 운지 표

**홈 줄**: 왼손 새끼 A · 약지 S · 중지 D · 검지 **F** / 오른손 검지 **J** · 중지 K · 약지 L · 새끼 ;. 엄지 둘은 스페이스 위에 있다.

| 손가락 | 왼손 | 오른손 |
|---|---|---|
| 새끼(f4) | `` ` 1 Q A Z ``, Tab · Caps · 왼 Shift · 왼 Ctrl, **Esc** | `0 - = P [ ] \ ; ' /`, Backspace · Enter · 오른 Shift |
| 약지(f3) | `2 W S X` | `9 O L .` |
| 중지(f2) | `3 E D C` | `8 I K ,` |
| 검지(f1) | `4 5 R T F G V B` | `6 7 Y U H J N M` |
| 엄지(t) | Space(오른손 엄지가 주로 침, 왼손은 쉼) · 왼 Alt | 오른 Alt |

**단축키**(왼손 새끼가 수정 키를 누른 채로 다른 손가락이 침)

| 단축키 | 손 |
|---|---|
| Ctrl+S(저장) | 왼 새끼 Ctrl 누른 채 왼 약지 S |
| Ctrl+C / Ctrl+V | 왼 새끼 Ctrl + 왼 중지 C / 왼 검지 V |
| Ctrl+Z | 왼 새끼 Ctrl + 왼 약지가 Z로(새끼 대신) |
| Ctrl+Shift+P | 왼 새끼 Ctrl + 왼 약지 Shift(아래로 뻗음) + 오른 새끼 P |
| Alt+Tab | 왼 엄지 Alt + 왼 새끼 Tab |

- 키는 손가락 끝(f*_3)이 키캡 윗면 가운데에 닿는 것으로 친다. 손은 홈 줄 위에 떠 있고, 위아래 줄 키는 그 손가락만 뻗거나 굽혀 닿는다(손바닥은 거의 그대로, 앞뒤 ±1 cm).

## 3. 리듬

| 요소 | 값 |
|---|---|
| 키 사이(같은 낱말 안) | **230 ms** 평균, 120–380 ms 고르게 흔들림. 같은 손 연속은 +40 ms, 양손 번갈아는 −30 ms |
| 겹쳐 누름 | 낱말 안 키의 30%는 앞 키가 올라오기 전에 다음 키를 누른다(서로 다른 손가락일 때만) |
| 키를 누르고 있는 시간 | 90 ms(70–120) |
| 낱말 버스트 | 3–9타(낱말 하나), 끝에 Space |
| 낱말 사이 멈춤 | 280 ms(Space 뒤) |
| 생각 멈춤 | 4–8 낱말마다 0.8–2.5초. 손은 홈 줄 위 1 cm에 떠서 쉰다(손가락 쉼 c) |
| 백스페이스 | 낱말 열에 하나꼴로 1–3번(오른 새끼 뻗음), 그다음 다시 1–3타 |
| 엔터 | 줄 끝(10–20 낱말마다), 오른 새끼. 엔터 뒤 0.4초 멈춤 |
| 에이전트 차이 | 루프는 **빠른 사람 쪽**(키 사이 170 ms, 겹쳐 누름 45%) · 메모 보통 · 메시 느리고 멈춤 길게(3D는 마우스 위주) · 휴 보통 + 백스페이스 잦음(고쳐 쓰기) · 에코 보통 + 멈춤 길게(듣기) |

- 키를 고르는 법: 실제 글자를 칠 필요는 없다. 영어 낱말 빈도 분포에 맞춘 가짜 낱말(예: 자주 쓰는 글자 e · t · a · o · i · n 비중 높게)을 시각 씨앗으로 뽑는다. 같은 키 연속은 피한다.

## 4. 활동별 키보드 : 마우스

| 활동(#110) | 키보드 : 마우스(시간) | 키보드 쪽 | 마우스 쪽 |
|---|---|---|---|
| `edit`(파일 편집) | 80 : 20 | 3절 리듬 그대로 | 4–6초마다 1–2초: 클릭으로 커서 옮기기, 가끔 휠 |
| `read`(파일 읽기) | 15 : 85 | 가끔 Ctrl+F · 화살표 | **휠** 위주(1.5초마다 2–4번 굴림), 가끔 클릭. 머리가 화면 위에서 아래로 천천히 내려감 |
| `run` · `test` · `build` · `install` · `git` | 40 : 60 | 명령 한 줄(8–20타) + 엔터 | 엔터 뒤 손을 마우스로 옮겨 결과를 휠로 내림 · 기다림. 기다리는 동안 손가락 톡톡(손가락 하나씩 c 0.3 → 0.5, 0.5초 간격) |
| `think`(#98) | 0 : 10, 나머지 쉼 | — | 손이 키보드 앞 1 cm 위에 떠서 쉼. 가끔 턱 받침 · 머리 톡톡(agents.md 버릇) |
| `delegate`(종이비행기 #51) | 60 : 40 | 짧은 메시지 한 줄 | 클릭 두 번 뒤 종이비행기 장면으로 |

- 키보드 ↔ 마우스 옮기기: 오른손만 0.35초 호(높이 3 cm)로 옮긴다. 왼손은 홈 줄에 남는다.
- 마우스 쥐기 · 클릭 · 휠 · 옮기기 손은 grips.md 마우스 네 행(마우스 · 마우스 버튼 · 마우스 휠 · 마우스 옮기기)을 따른다.

## 5. 키캡 눌림

- 키캡 노드는 키마다 따로 둔다(공통 키트 87개, 인스턴스 + 키마다 오프셋, 또는 정점 셰이더로 눌린 키만 아래로).
- **깊이 4 mm**(기계식 스위치 바닥까지), **누르는 시간 40 ms**(손가락이 닿은 순간부터), 돌아옴 60 ms(스프링, 살짝 넘침 0.3 mm).
- 2 mm에서 입력된 것으로 보고, 화면(#75 모니터) 글자는 그 순간 늘어난다(지금 모니터 표시는 상태만이라, 입력 줄 커서만 깜빡여도 된다).
- 기본 카메라에서는 4 mm가 보이지 않는다. 근접(둘러보기 어깨 너머 #207 · `?cam=`)에서만 보이면 된다.
- 소리(#194 `type`)는 키가 2 mm에 닿는 순간에 낸다.

## 6. 손 모양 정리

| 상태 | 손 |
|---|---|
| 홈 줄 쉼 | 손가락 c 0.45 · 0.45 · 0.5 · 0.55(끝이 홈 키 위 1 cm), 엄지 (0.2, 0.3) 스페이스 위 |
| 키 하나 치기 | 그 손가락만 c +0.12(누름) → 원래(올림). 위 줄은 손가락을 펴며(c −0.15) 뻗고, 아래 줄은 굽히며(c +0.15) 닿는다 |
| 겹쳐 누름 | 앞 손가락이 올라오는 중에 다음 손가락이 내려간다(동시에 두 손가락 움직임) |
| 백스페이스 · 엔터 | 오른 새끼가 c −0.2로 펴며 오른쪽으로 2–3 cm 뻗음, 손목 5° 바깥 |
| 스페이스 | 오른 엄지 굽힘 +0.15 |

## 7. 움직임 줄이기 · 배속

- 움직임 줄이기: 손가락 치기 대신 손이 홈 줄에 가만히 있고, 키캡 눌림 · 마우스 옮기기는 끈다. 모니터 상태만 바뀐다.
- 타임랩스 ×4: 리듬 그대로 4배. ×16: 손가락 치기를 끄고 손만 홈 줄에 둔다(#158 단순화).
- 기본 카메라에서는 손가락 하나하나가 보이지 않으므로, **멀리 있는 에이전트**(화면 높이 대비 머리가 40 px 미만)는 손가락 치기를 손 전체 미세 떨림(±2 mm)으로 줄여 비용을 아낀다.

## 8. 판정

- 근접(어깨 너머 #207 구도) 10초 연속 컷으로 본다.
  - 손가락이 맡은 줄을 오가는지
  - 같은 박자로 떨지 않는지
  - 멈춤 · 백스페이스가 보이는지
  - 키캡이 내려가는지
- 활동별로 30초씩(edit · read · test) 키보드 : 마우스 비율을 세어 4절 표와 대 본다.
- 실제 타이핑 영상(공개 영상, 링크만) 한 개와 나란히 본다.
