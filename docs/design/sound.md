# 사무실 소리 (#194)

> 2026-11-08 · 사운드 엔지니어 세션 · **초안**(디자이너 확인 → 🖊 결재 전)
> 기준 엔진: rowansong.dev `src/audio/audio.ts`(책상 방). 엔진 공유 방식과 호출 지점은 코더와 합의했다([#194 협의 기록](https://github.com/Rowan-Hyeho-Song/agent-office/issues/194#issuecomment-6719262471)).
> 세션은 소리를 귀로 듣지 못한다. 모든 판단은 `?debug` 소리 패널(8절)에서 사용자가 들어 보고 정한다. 숫자는 출발점이다.

## 1. 원칙

- **음원 파일 0.** 책상 방처럼 전부 Web Audio로 합성한다. 저작권을 따질 필요가 없고 용량이 0이다. 외부 음원 라이브러리도 쓰지 않는다.
- **같은 사이트의 소리.** 책상 방과 음계(A단조 · 72 BPM), 음색(삼각파 · 사각파 블립, 테이프 히스), 레벨(컴프레서 −18 dB · 3:1)을 맞춘다. 문을 지나도 "같은 사람이 만든 소리"로 들려야 한다.
- **듣는 사무실.** 소리는 분위기다. 정보를 소리로만 전하지 않는다. 모든 소리에는 같은 순간의 화면 변화가 있다(성공 = 신호등 초록, 도장 = 찍힌 자국). 소리를 꺼도 잃는 정보가 없다.
- **조용한 쪽으로.** 에이전트 다섯이 하루 종일 일한다. 하나하나는 작고 짧게 하고, 동시에 나는 소리 수를 묶는다(6절). 크게 들리는 것은 방문자가 직접 일으킨 것(누름 · 결재)뿐이다.
- **멀면 작게.** 듣는 위치는 카메라다. 3D 사물에서 나는 소리는 위치를 갖고, 멀어지면 작아지며 좌우로 갈린다. 화면 UI(HUD · 결재함)의 소리는 위치가 없다.

## 2. 구조

### 2.1 두 방, 두 컨텍스트

사무실은 책상 방 페이지 안의 iframe이다(rowansong.dev `RoomDoor.tsx`). iframe은 별도 문서라서 AudioContext를 하나로 쓸 수 없다. 두 방이 각자 컨텍스트를 갖고, 설정과 전환 시각만 메시지로 맞춘다.

| 무엇 | 정한 것 |
|---|---|
| 엔진 | agent-office `src/audio/`에 책상 방 엔진의 결(버스 · 컴프레서 · `beep` · 잡음 버퍼 · 레벨 상수)을 복사한다. 저장소와 빌드가 따로라 공용 패키지는 과하다. 파일 머리에 "rowansong.dev `audio.ts`와 레벨 기준을 맞춤"을 적는다 |
| 컨텍스트 만들기 | **첫 사용자 제스처 때만** 만든다. smoke가 콘솔 오류를 실패로 세고, 브라우저는 제스처 전 소리를 막는다 |
| 들어올 때 | iframe에 `allow="autoplay"`를 준다. 방문자는 부모 페이지(모니터 클릭 · `cd office`)에서 이미 제스처를 했다. 그래서 들어오자마자 사무실 소리를 켤 수 있다 |
| 따로 열었을 때 | 사무실만 따로 열면(`ROOM_MODE` 아님) START가 없다. 처음엔 **꺼짐**이고, HUD 소리 버튼이나 첫 클릭으로 켠다(9절 결재 1) |
| 탭이 숨으면 | 컨텍스트를 멈추고(`suspend`), 돌아오면 다시 켠다(책상 방과 같음) |

### 2.2 버스와 레벨

```
cue ─┬─ sfx ────┐
     ├─ voice ──┤
amb ─┴─ ambience┼─ master(볼륨) ─ 컴프레서(−18 dB, 3:1) ─ 출력
spk ─── music ──┘
```

| 버스 | 무엇 | 기준 게인 | 책상 방 |
|---|---|---|---|
| `music` | 스피커 음악(5절) | 0.12 | 배경음 0.14 |
| `sfx` | 효과음(4절) | 0.5 | 0.55 |
| `voice` | 로봇 말소리(4.3) | 0.45 | sfx 안에 있음 |
| `ambience` | 공간음(3절) | 0.10 | 테이프 히스가 music 안에 있음 |
| `master` | 방문자 볼륨 × 음소거 | 0–1 | 음소거만 |

- 사무실은 책상 방보다 조금 작게 시작한다. 책상 방은 혼자 듣는 방이고, 사무실은 여럿이 일하는 방이다.
- 말소리가 나는 동안 `music`을 −6 dB로 낮춘다(덕킹, 0.15초 내리고 0.6초 올림).

### 2.3 방 사이 전환 (크로스페이드)

책상 방의 들어가기 · 나가기 연출(rowansong.dev #6)에 맞춘다. 책상 방 쪽은 이미 있는 소리를 그대로 둔다.

| 단계 | 책상 방 | 사무실 |
|---|---|---|
| 들어가기 B(밀고 들어감) | 오르는 사인음 + 히스, 배경음 30%로 | — |
| C1(디가우스) | "쿵·웅" 뒤 배경음 0.6초에 0 | — |
| `entered`(`link.ts` `onEntered`) | 조용함 | 공간음 0 → 기준 **1.2초**. 스피커 음악은 켜져 있으면 2초 늦게 같이 오름 |
| 나가기 시작(`onLeaveStart`) | — | 사무실 전체 **0.6초**에 0 |
| X2 → 지직 | 내려가는 사인음 → CRT 지직, 배경음 0.8초에 돌아옴 | 꺼짐 |

두 방이 겹쳐 울리는 구간이 없다. 문 소리가 이음매를 덮는다.

### 2.4 설정 공유

| 무엇 | 정한 것 |
|---|---|
| 설정 | `{ muted: boolean, volume: 0–1 }` 두 개. 책상 방과 사무실이 같은 값을 쓴다 |
| 저장 | localStorage `rowansong.audio`(JSON). 배포에서는 두 방이 같은 출처라 그대로 공유된다. 읽기 · 쓰기는 try/catch(사생활 모드 예외) |
| 메시지 | protocol에 `audio` 타입을 더한다. 책상 → 사무실: `entered` 때 한 번, 바뀔 때마다. 사무실 → 책상: 사무실 HUD에서 바꿨을 때. 봉투 `{ns:'rowansong.room', v:1}`와 출처 허용 목록 검사를 그대로 거친다. volume은 0–1로 자르고, 모르는 필드는 버린다. dev에서는 두 방의 출처가 달라 메시지가 공유를 맡는다 |
| 음소거 반응 | 즉시. 10 ms 램프만 둔다(딸깍 방지) |
| 움직임 줄이기 | 소리와 관계없다. 움직임 줄이기를 켜도 소리는 그대로다. 반대로 소리를 꺼도 움직임은 그대로다 |

## 3. 공간음 (ambience)

빈 사무실에도 소리가 있다. 아주 작게 깔리고, 창밖(#111)의 시간대를 따라간다. 시계는 `officeNow(world)`이고, `?debug=1&kst=02:00`으로 바꿔 들을 수 있다.

| 층 | 합성 | 낮 | 밤 |
|---|---|---|---|
| 공조 | 갈색 잡음 → 저역 통과 180 Hz, 0.05 Hz로 아주 느리게 출렁임 | 기준 | −6 dB |
| 먼 도시 | 분홍 잡음 → 대역 통과 400 Hz(Q 0.5) | 기준 −4 dB | −12 dB |
| 지나가는 차 | 대역 통과 잡음이 3–5초에 걸쳐 커졌다 작아짐, 좌 → 우로 이동. 낮 40–90초에 한 번 | 있음 | 3–6분에 한 번 |
| 형광등 험 | 사인 120 Hz + 240 Hz, 아주 작게 | 없음 | 퇴근 뒤 불이 남은 자리 근처에서만(3D) |

- 시간대 경계는 `outside.ts`의 `PERIODS`(새벽 5시 · 낮 7시 · 저녁 17시 · 밤 20시)를 그대로 쓴다. 바뀔 때는 `BLEND_MIN`(10분)에 걸쳐 섞는다.
- 공간음은 위치가 없다(방 전체). 형광등 험만 예외다.
- 공간음이 사무실의 "기본 소리"다. 방문자가 아무것도 하지 않을 때 들리는 것은 공간음, 타자 소리 몇 개, 가끔 스피커 음악뿐이다.

## 4. 효과음

### 4.1 1차 묶음 (10개)

- **레벨**은 책상 방 `beep()`의 `level`과 같은 눈금이다. 책상 방 클릭은 0.04, 성공은 0.05다.
- **3D**는 위치를 갖는 소리다(거리 감쇠 · 좌우).
- **훅**은 코더와 정한 호출 지점이다. ①은 결재 뒤 바로 하고, ②는 #184 · #186 병합 뒤 한다.

| # | cue | 언제 (훅) | 음색 | 길이 | 레벨 | 3D | ×4 / ×16 |
|---|---|---|---|---|---|---|---|

- **방문자가 일으킨 소리**(8 · 결재함 도장 · HUD 누름)가 가장 크다. 에이전트가 하는 일(1–6, 9–10)은 그보다 작다.
- 음높이가 있는 소리는 A단조 펜타토닉(A · C · D · E · G) 안에서 고른다. 스피커 음악과 겹쳐도 어긋나지 않는다(책상 방 버섯 4음과 같은 규칙).
- 같은 cue가 짧은 간격으로 이어지면 음높이를 ±3% 흔든다. 기계 반복처럼 들리지 않게 하려는 것이다.

### 4.3 로봇 말소리 (voice)

말풍선에 글자가 찍히는 동안 책상 방 `voice()`의 옹알이를 쓴다. 성대 같은 톱니파에 모음 포먼트를 건 소리다. 에이전트마다 음높이를 나눈다.

| 에이전트 | 음높이 배수 | 결 |
|---|---|---|
| 메모 | 1.0 | 기준 |
| 메시 | 0.85 | 낮고 짧게 끊음 |
| 휴 | 1.15 | 높고 밝게 |
| 루프 | 0.95 | 사각파 쪽, 건조하게 |
| 에코 | 1.05 | 꼬리에 짧은 메아리(0.12초, 되먹임 0.2) |

- 한 번에 한 명만 말소리를 낸다. 회의에서는 지금 줄의 화자만 낸다.
- 회의록 재연이 길면 첫 문장만 소리를 내고, 나머지는 글자만 찍는다(10초 이상 웅얼거림 방지).

## 5. 스피커 음악

에코 책상의 스피커 한 쌍(#193)이 사무실 음악의 실제 음원이다.

- **음악**: 책상 방 배경음과 같은 진행(Am9 – Fmaj9 – Cmaj7 – G6, 72 BPM)이다. 악기만 바꾼다. 톱니파 패드 대신 일렉트릭 피아노(사인 + 2배음, 느린 트레몰로), 같은 서브 베이스, 테이프 히스는 조금 더 낀다. "같은 곡을 다른 방에서 트는 소리"를 노린다.
- **위치**: 스피커 두 개에서 각각 난다(3D, 왼쪽 · 오른쪽 채널을 나눔). 가까이 가면 커지고, 방 반대편에서는 공간음 밑으로 깔린다.
- **언제 켜지나**
  - 에이전트 둘 이상이 쉬는 중(놀이 · 커피 · 소파)일 때 에코가 튼다. 에코가 자리에 없어도 튼다(믹서 페이더가 올라감).
  - 모두 일하면 아주 작게(−12 dB) 계속 돈다.
  - 밤(23–09 KST, `isNight`)에는 꺼진다. 밤 당번이 있으면 그 자리 근처 형광등 험만 남는다.
- **방문자 조작**: 스피커를 누르면 음악이 켜지고 꺼진다(그 방문자에게만, 저장 안 함). 스피커 LED와 믹서 페이더가 같이 움직인다(#193 LIVE).
- **실제 소리와 3D 잇기**: `AnalyserNode`로 음악 크기를 재서 스피커 우퍼 · 레벨 미터 · 에코 뒤통수 그릴 빛을 움직인다(#193). 소리가 꺼지면 멈춘다.

| 규칙 | 값 | 이유 |
|---|---|---|
| 거리 감쇠 | `PannerNode` `inverse`, 기준 거리 2 m, 감쇠율 1, 최대 12 m. 패닝은 `equalpower`(HRTF 안 씀) | 방이 9 × 7 m. HRTF는 휴대폰에서 무겁다 |
| 동시 효과음 상한 | 6개. 넘치면 가장 작게 들리는(멀거나 레벨이 낮은) 새 소리를 버린다 | 다섯 명 + 놀이가 겹쳐도 지저분하지 않게 |
| 같은 cue 최소 간격 | `type` 38 ms(책상 방과 같음), 그 밖 80 ms | 버징 방지 |
| 카메라 밖 | 화면에 안 보이는 에이전트의 반복음(`type` · `water` · `hover`)은 내지 않는다. 사건음은 낸다(작게) | "보이는 것이 들린다" |
| 타임랩스 | 재생 시계 τ로 사건을 계산한다. ×1은 그대로, ×4는 반복음 절반 · 사건음 −3 dB, ×16(`rig.ambient === 0`)은 반복음 없음 · 사건음만 −6 dB. 되감기 · 건너뛰기(`seek`)로 지나친 사건은 소리를 내지 않는다 | 빨리 감을 때 소음 벽이 되지 않게 |
| 덕킹 | 말소리 중 음악 −6 dB | 말풍선이 주인공 |

## 7. 성능 예산

| 항목 | 상한 | 방법 |
|---|---|---|
| 동시에 살아 있는 오디오 노드 | 약 80개 | 효과음은 끝나면 바로 연결을 끊는다. 공간음 · 음악 그래프는 고정 |
| 잡음 버퍼 | 2초짜리 셋(흰 · 분홍 · 갈색)을 처음에 한 번 만든다 | 효과음마다 버퍼를 새로 만들지 않는다(책상 방 `print`만 예외) |

## 8. 확인 방법

### 8.1 `?debug` 소리 패널 (사용자가 들어 보는 곳)

`DebugPanel`의 `BubbleDebug`처럼 붙인다.

- **cue 목록**: 4절의 모든 cue에 ▶ 버튼을 둔다. 3D cue는 "가까이 · 멀리 · 왼쪽 · 오른쪽" 위치를 골라 들을 수 있다.
- **버스 페이더**: music · sfx · voice · ambience · master. 지금 값을 숫자로 보인다.
- **공간음 시간대**: 새벽 · 낮 · 저녁 · 밤을 바로 바꿔 듣는다(`kst=` 없이).
- **스피커 음악**: 켜기 · 끄기 · 일하는 중(−12 dB) 비교.
- **책상 방과 비교**: 같은 이름의 cue(click · success 등)를 책상 방 레벨로 한 번, 사무실 레벨로 한 번 연달아 낸다.
- **미터**: master 출력의 순간 피크(dBFS)와 3초 평균 크기.

### 8.2 숫자로 재기

세션은 귀 대신 숫자로 확인한다.

- 각 cue를 `OfflineAudioContext`로 그려서 피크 dBFS와 단기 크기(K 가중, LUFS 근사)를 잰다. 테스트(`*.test.ts`)에 넣어 한도를 지킨다.
  - 효과음 피크: master 뒤 −6 dBFS 이하
  - 공간음: −50 LUFS 근처
  - 음악(스피커 앞): −30 LUFS 근처
- 같은 방법으로 책상 방 cue도 재서 기준 표를 만든다. 두 방의 같은 cue가 ±2 dB 안에 있어야 한다.
- `pnpm smoke`(8조합)와 `pnpm a11y`에서 콘솔 오류가 0이어야 한다. 제스처 전에는 컨텍스트가 없어야 한다.
