> - 다음 순서: 이 문서 → 3D 리그(엄지 뿌리 · 손가락 벌림 축) → 코더 자세 엔진 → 키보드(typing.md) · 쥐기(grips.md) 다시 맞춤

**근거**
- 정상 관절 범위: 손가락 MCP 0–90°(과신전 최대 45°), PIP 0–100°, DIP 0–80°, 엄지 손바닥 쪽 벌림 0–60°([Queen's University 임상 표](https://elentra.healthsci.queensu.ca/community/carpaltunnelsyndrome:clinical_presentation/physical/motor)). 엄지 MCP 굽힘 50°, IP 80°([PRS Global Open 보충표](https://cdn-links.lww.com/permalink/prsgo/b/prsgo_8_6_2020_04_17_hendriks_gox-d-20-00155r2_sdc1.pdf)).
- 끝마디는 가운데 마디를 따라 굽는다: DIP ≈ 0.77 · 0.75 · 0.75 · 0.57 × PIP(검지 · 중지 · 약지 · 새끼, Mentzel 외 2011, [PeerJ 정리](https://peerj.com/articles/14051)). 이 둘은 힘줄 하나로 묶여 따로 굽히기 어렵다([지간 관절](https://wikipedia.com/wiki/Proximal_interphalangeal)).
- 일상 동작은 능동 범위의 작은 부분만 쓴다(Hume 외 1990, J Hand Surg Am 15(2), [PubMed 2324451](https://pubmed.ncbi.nlm.nih.gov/2324451/)). 그래서 자세는 대부분 범위의 70% 안에 두고, 끝값은 주먹 · 가리키기에만 쓴다.
- 자세 종류는 사람 쥐기 분류(힘 쥐기 / 정밀 쥐기, Napier 1956 · Feix 외 2016 *GRASP taxonomy*)에서, **화면에서 실루엣이 갈리는 것**만 골랐다.

## 1. 관절 · 축 · 한계

**3D 리그 변경**
- 손가락 뿌리 마디 `_f{n}_1`에 벌림 축(로컬 z)을 쓴다. 회전 순서는 **벌림 먼저, 그 틀에서 굽힘**이다(q = q벌림(z) · q굽힘(x)).
- 엄지
  - 새 노드 `…_t_0`(엄지 두덩)를 둔다. 손바닥 엄지 쪽 아래 모서리(손목 쪽)에서 0.015 안이 피벗이다. 모양은 손바닥과 같은 `bot_shell` 쐐기 0.03 × 0.022 × 0.02이고, 모서리는 0.006이다.
  - 지금 `_t_1`(굽힘 + 맞섬 두 축)은 `_t_0`의 자식이 되고, 굽힘 한 축(MCP)만 남긴다. `_t_2`(IP)는 그대로다.
  - 엄지를 벌려도 손바닥과 엄지 사이가 비어 보이지 않게, 쐐기가 그 틈을 메운다.
- 관절 핀은 `_t_0` ↔ `_t_1`에 하나를 더한다. 삼각형은 손 하나 +약 60(1.4k 상한 안)이다.

## 2. 이름 붙인 자세

- 손가락 칸은 **MCP 굽힘 / PIP**이다(DIP는 위 비율로 따라감, 따로 적은 것만 예외).
- 벌림은 검지 · 중지 · 약지 · 새끼 순서다.
- 엄지 칸은 **CMC 굽힘 / CMC 벌림 / MCP / IP**이다.
- "보임"은 기본 카메라(손 약 13 px)와 가까이(둘러보기 · 확대, 40–80 px)에서 실루엣이 갈리는지다.

- **고른 기준**: 기본 카메라(손 약 12 px)에서 실루엣으로 갈리는 것은 **펼침 · 가리키기(ㄱ자 틀 포함) 둘**이다(#298 앱 판정 시트). 처음 적은 "주먹 · 엄지 척까지 넷"은 실제로 갈리지 않았다.
  - 멀리서 읽혀야 하는 몸짓(반가움 · 이김 · 뿌듯)은 펼침이나 주먹에 **손 움직임**(흔들기 · 위로 올림 · 톡)을 더해서 낸다. 손 모양만으로 알리지 않는다.
  - 나머지는 가까이(둘러보기 · 확대 · 오목 컷)에서 손가락 모양이 갈리는 쥐기용이다.
- **손 값의 기준은 앱 측정이다**: `pnpm hand:measure [--pose id] [--angles '…']`(#298). 손끝은 끝마디 끝 가운데(A)로 잰다. 3D Blender 덤프와 관절 · 손끝이 같게 맞춰졌다.
- **집기 셋 값**(2026-11-10, 앱 측정)
  - 앞서 적은 값(2.1 · 0.8 · 1.4 mm, 그다음 1.2 · 0.7 · 3.8 mm)은 미리 굽힌 손을 휴식으로 잡은 것과 손끝 정의 차이(손등 쪽 점) 때문에 틀렸다.
  - 옛 표 손가락 값으로는 엄지를 어떻게 해도 닿지 않아, 검지(세 손가락은 중지도)를 55 / 70 · DIP 54로 더 굽혔다(뿌리 63° 이하).
  - 앱에서 잰 거리: 끝 집기 **1.9 mm**, 세 손가락 집기 **0.6 mm**(검지 · 중지 끝 가운데), 옆 집기 **1.8 mm**(검지 가운데 마디 면). 옆 집기는 손가락을 표 그대로 두고 엄지만 바꿨다.
  - **자세 기준은 5 mm 안**이다. 실제 물건을 쥘 때는 grips.md 1의 접촉점 보정(3 mm)이 그 위에 붙는다.
  - 주먹 · 가리키기 · 감아 쥐기는 표 값 그대로 엄지가 손가락 앞을 덮는다.
- **벌림(CMC)은 엄지를 손바닥 앞으로 들어 올리는 축**이다. 옆으로 펴는 것은 굽힘 음수(−15)로 한다. 펼침에 벌림을 크게 주면 엄지가 손바닥 앞으로 7 cm 들린다.
- **ㄱ자 틀**(메시)은 가리키기에 엄지만 펼침과 같은 −15 / 10 / 0 / 0으로 바꾼다. **손바닥 도장**(메모)은 받치기를 손바닥 아래로 둔 것이다.

**자세 사이 · 움직임**
- 자세 사이는 120 ms에 각도를 섞는다(지금과 같음). 쥘 때는 검지 → 새끼 순서로 15 ms씩 늦게 닫고, 놓을 때는 반대 순서로 연다. 사람 손이 한꺼번에 닫히지 않는 것을 작게 흉내 낸다.
- 쉼에 오래 있으면 손가락마다 따로 ±3°, 4–7초 주기로 아주 작게 움직인다(살아 있는 손). 움직임 줄이기면 끈다.
- 접촉점 보정(grips.md 1: 손끝이 접촉점 3 mm 안)은 MCP · PIP를 같이 고치고, DIP는 비율을 따라간다.

## 3. 지금 c 값을 옮기는 규칙

지금 표(grips.md · typing.md · play.md · agents.md 2.7)는 손가락마다 굽힘 c(0–1), 엄지 (굽힘 b, 맞섬 o), 사이 s(°)로 적혀 있다. 다시 쓰지 않고 아래 식으로 옮긴다. 새로 쓰는 표는 2절 이름 + 바꾼 각도로 적는다(예: "감아 쥐기, 새끼 MCP 75").

| 옛 값 | 새 각도 |
|---|---|
| 손가락 c | MCP = 85 · c, PIP = 100 · c, DIP = k · PIP(k = 0.77 · 0.75 · 0.75 · 0.57) |
| 사이 s | 벌림 검지 +s, 중지 0, 약지 +s, 새끼 +2s(손가락 사이 간격이 모두 s가 됨) |
| 엄지 굽힘 b | MCP = 50 · b, IP = 70 · b |
| 엄지 맞섬 o ≥ 0 | CMC 굽힘 = 35 · o, CMC 벌림 = 20 + 30 · o |
| 엄지 맞섬 o < 0(바깥) | CMC 굽힘 = −15 · \|o\|, CMC 벌림 = 10(벌림은 손바닥 앞으로 들리는 축이라 바깥으로 펼 때 키우지 않는다) |

- 예: 쉼(옛 0.25 · 0.25 · 0.30 · 0.35, 엄지 0.2 / 0, 사이 4) → MCP 21 · 21 · 26 · 30, PIP 25 · 25 · 30 · 35, 엄지 CMC 0 / 20, MCP 10, IP 14. 2절의 쉼(1번)과 거의 같다.
- 옮긴 값이 1절 한계를 넘으면 한계에서 자른다. 자른 자세는 코더가 목록으로 알려 주면 표를 다시 본다.

## 4. 판정

- **측정은 `pnpm hand:measure`로 한다**(앱과 같은 glb · 같은 관절 수학, 자세마다 관절 값 · 손끝 좌표 · 거리 · 합격 여부 표. `--pose` · `--agent` · `--side` · `--json` · `--angles`, 앞머리에 좌표계 설명).
- 앱 디버그로 14 자세를 한 손씩 강제로 띄운 표를 찍는다. 가까이(손 80 px)와 기본 카메라(13 px)에서 같은 크기로 나란히 놓는다.
- 사람 손 사진(공개 이미지 링크, 올리지 않음)과 자세마다 나란히 본다.
- 볼 것
  - 기본 카메라에서 펼침 · 주먹 · 가리키기 · 엄지 척이 갈리는지
  - 끝 집기 · 세 손가락 집기에서 손끝이 실제로 만나는지(5 mm 안)
  - 엄지가 손바닥에서 떨어져 보이지 않는지(엄지 두덩 쐐기)
  - 관통 0
