- 바닥은 지금도 122 px/m로 목표(200) 아래이고, 방을 키우면 더 내려간다(안 3 약 101).
- **바닥을 아틀라스 하나로 따로 뺀다**(바닥만 2048). 안 3 바닥 78.7 m²에서 약 210 px/m가 된다(섬 쓰임 90%). 깔개 · 패드는 room에 남겨, room 밀도도 같이 오른다.
- `room --size 4096`보다 이쪽을 고른 이유: 바닥만 나뭇결 해상도가 필요하고, 용량이 약 +0.2 MB로 적다.
- 모델 합계 추정: 4.4(5절) + 0.2 + 6절 물체 약 +0.2 = **약 4.8 MB**(상한 5 MB). 넘으면 6.2(보통)부터 뒤로 미룬다.
